Shader Web Background Toolkit

Built with shader-web-background by xemantic • Claude • cursor.com

A complete development environment for creating WebGL shader backgrounds. This project includes AI-assisted Shadertoy conversion rules, a shader registry system, and example implementations ranging from simple gradients to complex raymarched fractals.

🚀 Quick Start: Check out the minimal example for a clean, self-contained integration example.

GitHub Repository: https://github.com/MRKNSTUDIO/shader-background

🎯 What This Project Does

This toolkit solves the common problem of porting Shadertoy shaders to production websites. While Shadertoy uses WebGL 2.0 features, most production sites need WebGL 1.0 compatibility. This project provides:

  • AI Conversion Rules: Comprehensive .cursor rules that teach any AI assistant how to convert Shadertoy code automatically
  • Shader Registry: A clean JavaScript API for registering and switching between multiple shaders
  • Working Examples: From simple gradients to complex multi-pass feedback loops
  • Interaction Handling: Mouse, scroll parallax, and device orientation support

🤖 AI Conversion Rules

The .cursor/rules/converting-from-shadertoy.mdc file contains comprehensive conversion instructions for AI assistants. When working with Shadertoy code, the AI will automatically:

  • Convert mainImage() → main() entry point
  • Replace fragCoord / fragColor with GLSL equivalents
  • Fix iResolution type mismatch (vec3 → vec2)
  • Rewrite complex for-loops to WebGL 1.0 compatible form
  • Implement missing functions like tanh(), isnan(), round()
  • Expand problematic macros and fix variable shadowing
  • Convert texture() → texture2D()

📝 Adding Your Own Shaders

Step 1: Add shader source to index.html

<script type="x-shader/x-fragment" id="my-shader-image">
precision highp float;
uniform float iTime;
uniform vec2 iResolution;

void main() {
    vec2 uv = gl_FragCoord.xy / iResolution;
    vec3 col = 0.5 + 0.5 * cos(iTime + uv.xyx + vec3(0, 2, 4));
    gl_FragColor = vec4(col, 1.0);
}
</script>

Step 2: Create registration file shaders/my-shader.js

ShaderRegistry.register('my-shader', {
  shaders: {
    'my-shader-image': {
      uniforms: {
        iTime: (gl, loc) => gl.uniform1f(loc, performance.now() / 1000),
        iResolution: (gl, loc, ctx) => gl.uniform2f(loc, ctx.width, ctx.height)
      }
    }
  }
}, '<strong>My Shader</strong> Custom description here.');

Step 3: Add dropdown option and script include in index.html

<option value="my-shader">My Shader</option>
<script src="shaders/my-shader.js"></script>

🔄 Multi-Pass Shaders (Feedback Buffers)

For shaders that need previous frame data (trails, blur, reaction-diffusion), use a two-pass setup:

// Buffer pass: reads from itself, writes processed result
'my-shader-buffer': {
  uniforms: {
    iChannel0: (gl, loc, ctx) => ctx.texture(loc, ctx.buffers['my-shader-buffer']),
    iResolution: (gl, loc, ctx) => gl.uniform2f(loc, ctx.width, ctx.height)
  }
}

// Image pass: reads buffer and outputs to screen
'my-shader-image': {
  uniforms: {
    iChannel0: (gl, loc, ctx) => ctx.texture(loc, ctx.buffers['my-shader-buffer']),
    iResolution: (gl, loc, ctx) => gl.uniform2f(loc, ctx.width, ctx.height)
  }
}

The library handles double-buffering automatically—you read from the previous frame and write to the current frame.

🖱️ Mouse & Gyro Interaction

The library provides coordinate conversion helpers. Handle events in your application code:

// Track mouse position
let mouseX = 0, mouseY = 0;
document.addEventListener('mousemove', (e) => {
    mouseX = e.clientX;
    mouseY = e.clientY;
});

// Convert in onBeforeFrame callback
onBeforeFrame: (ctx) => {
    shaderMouseX = ctx.toShaderX(mouseX);
    shaderMouseY = ctx.toShaderY(mouseY);
}

// Pass as uniforms
uniforms: {
    iMouse: (gl, loc) => gl.uniform2f(loc, shaderMouseX, shaderMouseY)
}

Device orientation uses the same pattern with deviceorientation events and beta/gamma values.

⚡ Quick Shadertoy Conversion Checklist

  • Add precision highp float; at top
  • Declare uniforms: iTime, iResolution, iChannel0...
  • mainImage(out vec4 fragColor, vec2 fragCoord) → void main()
  • fragCoord → gl_FragCoord.xy
  • fragColor → gl_FragColor
  • vec3 r = iResolution → vec3 r = vec3(iResolution, 1.0)
  • Complex for-loops → simple for(int i=0; i<N; i++) with break
  • tanh(x) → custom implementation
  • isnan(x) → x != x
  • texture() → texture2D()
